WHAT WE'RE BUILDING

Search with sources at its centre.

Bubbles is Box Signal's experimental search technology. Its crawler discovers permitted public webpages, extracts readable information and organises it into a searchable index. The aim is to represent original websites faithfully, with clear source links and crawl dates — rather than presenting unsupported AI guesses.

01 / Discover

Follow public links, manage a persistent crawl queue and revisit pages as the index grows.

02 / Understand

Collect titles, headings, page text and image references while retaining the original sources.

03 / Search

Build relevant web and image results from retrieved information, with transparent attribution.

DEVELOPMENT

From a search box to a search engine.

Early local prototypes have crawled and stored webpages in a SQLite database. Work is continuing on crawler reliability, discovery, ranking, image indexing and a public search API.

THE BIGGER IDEA

Powered by Bubbles.

Bubbles is being developed as the underlying search engine. A separately branded public search website could use its index and API in the future. The public name and domain have not yet been chosen.
